# Unify the MyRhythm colour system

Apply the confirmed five-colour palette across the launch app while preserving every screen, feature, and flow.

## Palette
- Deep emerald: primary backgrounds, headers, and strong anchors
- Pale tan: warm page backgrounds and quiet surfaces
- Gold: fine borders, progress details, and premium highlights
- Burnt orange: primary actions and moments requiring attention
- Teal: supportive guidance, active states, and secondary highlights

## Implementation
- Consolidate these colours into the existing semantic design tokens so screens remain consistent and accessible.
- Replace remaining off-brand launch colours where they compete with the five-colour system.
- Keep burnt orange as the main action colour; teal remains a supporting accent rather than a competing primary action.
- Check key onboarding, Home, Memory Bridge, assessment, calendar, and settings screens at desktop and phone widths.
- Preserve all content, navigation, behaviour, and accessibility requirements.
